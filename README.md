# 07 — Preuves

Preuves justificatives classées par nature technique, indépendamment du projet
dont elles sont issues (le lien projet ↔ preuve est fait dans les fiches de
`06-projets/` et dans `09-correspondances/`).

- `specifications/` — Cahiers des charges, spécifications fonctionnelles et techniques
- `schemas/` — Schémas électroniques, schémas-blocs, architectures
- `simulations/` — Résultats et fichiers de simulation
- `code/` — Extraits de code / firmware / VHDL
- `pcb/` — Fichiers et documents relatifs aux circuits imprimés (routage, gerbers, BOM)
- `mesures/` — Relevés de mesures, résultats expérimentaux
- `tests/` — Protocoles et rapports de tests / validation
- `documentation/` — Documentation technique rédigée par le candidat

Chaque sous-dossier contient un `README.md` précisant les pièces attendues.
Ce sont ici des dossiers vides destinés à accueillir les pièces réelles du
candidat.
